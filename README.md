# 对称画布工具 (Symmetry Canvas Tool)

一个简单但功能强大的对称绘画工具，允许用户在不同对称模式下进行创意绘画。

## 特点

- **水平对称**：绘画将沿水平中线对称
- **垂直对称**：绘画将沿垂直中线对称
- **中心对称**：绘画将通过中心点进行对称
- **组合对称**：可以同时启用多种对称模式
- **显示对称轴**：可显示或隐藏虚线对称轴，帮助精确绘画
- **自定义画笔**：可调整颜色和大小
- **支持触摸设备**：适用于移动设备和平板电脑

## 使用方法

1. 打开 `index.html` 文件在浏览器中运行应用
2. 选择所需的对称模式（可以多选）：
   - 水平对称
   - 垂直对称
   - 中心对称
3. 可选择"显示/隐藏对称轴"按钮，在画布上显示虚线对称轴：
   - 水平对称轴显示为红色虚线
   - 垂直对称轴显示为蓝色虚线
   - 中心对称点显示为绿色圆点
   - 注意：只会显示已激活的对称模式对应的对称轴
4. 使用画笔工具在画布上进行绘画
5. 根据需要调整画笔颜色和大小
6. 使用"清除画布"按钮重新开始

## 技术细节

该应用使用纯HTML, CSS和JavaScript构建，不需要任何外部依赖。

- **HTML5 Canvas**：用于绘画功能
- **响应式设计**：适配不同屏幕尺寸
- **触摸支持**：适用于移动设备

## 文件结构

- `index.html` - 主HTML文件
- `style.css` - 样式表
- `script.js` - JavaScript功能实现

## 开始使用

只需将所有文件下载到同一目录，然后在浏览器中打开`index.html`文件即可开始使用。
